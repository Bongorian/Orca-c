# Orca C Android Port

This directory contains an Android front end for the upstream Orca C engine.
It is intended to live inside the Orca C source tree and reuse the upstream C
runtime directly through JNI.

Upstream Orca C:

```text
https://github.com/hundredrabbits/Orca-c
```

Port branch:

```text
https://github.com/Bongorian/Orca-c/tree/android-app
```

## Status

This is a prototype Android port. The app runs the Orca C VM, provides a
touch-friendly terminal-style editor, and can send generated MIDI, OSC, and raw
UDP events from an Android device.

The current native build target is `arm64-v8a` only.

## What Is Ported

- Orca C VM execution through a small JNI bridge.
- Full-screen Android editor with a monospace Orca grid.
- Touch cursor placement and drag scrolling for larger grids.
- Hardware/software keyboard editing.
- Playback loop with BPM, seed, tick, play/stop, step, and reset controls.
- Grid resize and auto-fit actions.
- App-private open/save using a configurable file name.
- Android `VIEW`, `EDIT`, and `SEND` intents for opening or sharing Orca text.
- Android MIDI output device selection.
- MIDI note, MIDI CC, and pitch bend event dispatch.
- OSC integer messages and raw UDP string event dispatch.
- Auto-save/restore using Android `SharedPreferences`.
- Optional keep-screen-awake mode.
- Android launcher icon and app label.

## Layout

```text
android/
  build-native.sh
  app/
    build.gradle
    src/main/
      AndroidManifest.xml
      cpp/native_bridge.c
      java/com/hundredrabbits/orcac/MainActivity.java
      java/com/hundredrabbits/orcac/OrcaNative.java
      res/
```

Important pieces:

- `build-native.sh` compiles the upstream C engine plus the JNI bridge into
  `app/src/main/jniLibs/arm64-v8a/liborcacore.so`.
- `native_bridge.c` owns the native Orca session, grid conversion, VM stepping,
  and event serialization.
- `OrcaNative.java` exposes the JNI calls to the Android app.
- `MainActivity.java` contains the full-screen editor, menus, persistence,
  file/share intent handling, MIDI output, and OSC/UDP output.

## Requirements

- Android SDK with platform 34 available.
- Android build tools 35.0.1 available.
- Android NDK 27.2.12479018, or set `ANDROID_NDK_HOME` to another compatible NDK.
- A Java/Gradle environment capable of running the included Gradle wrapper.
- A connected Android target for install/testing.

If Gradle cannot find the Android SDK, create `android/local.properties`:

```properties
sdk.dir=/path/to/android-sdk
```

`local.properties` is intentionally ignored by git.

## Build

From the repository root, build the native core first:

```sh
android/build-native.sh
```

Then build the APK:

```sh
cd android
./gradlew assembleDebug
```

The debug APK is produced at:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Install

```sh
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

If streamed install fails on the target ROM, push the APK first and install it
through Android package manager:

```sh
adb push android/app/build/outputs/apk/debug/app-debug.apk /data/local/tmp/orca-c-debug.apk
adb shell pm install -r /data/local/tmp/orca-c-debug.apk
```

## Using The App

- Tap a grid cell to move the cursor.
- Drag the grid to scroll when the grid is larger than the screen.
- Type printable ASCII characters to edit the grid. Spaces are stored as dots.
- Use `F1` or `Ctrl+D` to open the main menu.
- Swipe left from the right edge to open the main menu.
- Swipe right while a menu is open to close it.
- Use `Ctrl+Space` to start or stop playback.
- Use `Ctrl+F` to step one frame.
- Use `Ctrl+R` to reset the VM from the current grid.
- Use `Insert` or `Ctrl+I` to toggle append/overwrite editing.
- Use arrow keys to move the cursor.
- Use `Shift+Arrow` to grow the selection.
- Use `Alt+Arrow` to move the selected block.

The main menu includes New, Open, Save, Save As, BPM, grid sizing, OSC output,
MIDI output, clock settings, Android settings, and Close.

## Event Output

The JNI bridge serializes Orca events into a simple internal wire format. The
Android UI reads that format after each VM step and dispatches enabled outputs.

- MIDI note events are sent as note on/off pairs. Mono events clear existing
  notes on the same channel before sending the next note.
- MIDI CC events are sent as standard controller messages.
- MIDI pitch bend events are forwarded as standard three-byte pitch bend
  messages.
- OSC integer events are sent as OSC messages to the configured host and port.
- UDP string events are sent as raw datagrams to the same host and port.

The default OSC/UDP target is `127.0.0.1:49162`.

## Generated Files

These files are generated locally and should not be committed:

- `android/local.properties`
- `android/.gradle/`
- `android/build/`
- `android/app/build/`
- `android/app/.cxx/`
- `android/app/src/main/jniLibs/arm64-v8a/liborcacore.so`
- APK files
- signing keys and keystores

The native library is generated by `android/build-native.sh` from source.

## Limitations

- Prototype UI; this is not a Play Store release package.
- Native output currently targets `arm64-v8a` only.
- Release signing, versioning, and multi-ABI packaging are not set up yet.
- Open/save uses app-private storage for named files. Android share/open intents
  can import text from other apps, but there is no Android document provider
  based save-as flow yet.
- OSC and UDP use the same configured host and port.

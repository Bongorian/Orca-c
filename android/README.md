# Orca C Android

Android front end for the upstream Orca C engine.

This directory is intended to live inside the Orca C source tree. It builds an
Android app that embeds the Orca C VM through JNI and adds touch-friendly
editing, Android file/share integration, and MIDI output selection.

## Upstream

The core Orca C source is from:

```text
https://github.com/hundredrabbits/Orca-c
```

The upstream project is MIT licensed. See the repository root `LICENSE.md`.

## Build

From the repository root, build the native core first:

```sh
android/build-native.sh
```

Then build the APK:

```sh
cd android
./gradlew assembleDebug
```

The debug APK is produced at:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Install

```sh
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

If streamed install fails on the target ROM, use:

```sh
adb push android/app/build/outputs/apk/debug/app-debug.apk /data/local/tmp/orca-c-debug.apk
adb shell pm install -r /data/local/tmp/orca-c-debug.apk
```

## Notes

- `local.properties`, Gradle output, CMake output, and APK files are ignored.
- `app/src/main/jniLibs/arm64-v8a/liborcacore.so` is generated by
  `android/build-native.sh` and is not source.
